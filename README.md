## Projects

[CJTaskrunner](https://github.com/jgusta/cjtaskrunner)
An independent command line task runner designed as a catalog of runnable tasks. Deliberately simple, with no shell dependency, no expression language, with optional directives that take no arguments, are scope-limited. An executable name that is at least two characters shorter than other task runners.

[`paths.fish`](https://github.com/jgusta/paths)
A plugin for fish shell users that outputs the complete lineage of a named executable command, including executables in $PATH, autoloaded fish functions, and builtins. 

[`match`](https://jsr.io/@jgusta/match)
A pattern-matching utility for use in Typescript.

[Fragment Shader Flavor Converter](https://vfast.slowgaffle.com)
A web-based tool to translate application-specific fragment shader code (GLSL and HLSL) into another format i.e. Shadertoy, GLSL Sandbox, VS, ISF, WebGL. Unlike other such tools, this uses an intermediate representation which makes it extensible (in theory) to other languages. 

[Print calendar maker](https://calendar.eol.lol)
For when you need to just print a calendar for a month.

## Dumb things

And a couple things with about a middle-school level sophistication:

[Amazon Vendor Name Generator](https://amazonname.pages.dev)
Ever heard of the brands Rominacus, Foamrida, CateCoop, Enceleaf or Enjoyella? No you haven't. The Amazon Business Name Generator just generated these. Based on in-depth research of off-brand vendor and product names, this project emulates the actual thought process of choosing the most legitimate-sounding names for your Amazon business.

[Filler text Generator using dialog from the film The Departed](https://departed.slowgaffle.com)
